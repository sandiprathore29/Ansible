**What is Ansible ?**

Ansible is an open-source IT automation tool used for configuration management, application deployment, orchestration, and task automation.

**features of Ansible**

**Agentless** – No need to install agents on remote servers.\n
**Simple YAML Syntax** – Uses playbooks written in YAML.
**Idempotent** – Ensures that tasks only make changes when necessary.
**Secure & Lightweight** – Uses OpenSSH for communication.
**Scalable** – Can manage thousands of servers simultaneously.
**Declarative & Procedural** – Supports both approaches to configuration management.
